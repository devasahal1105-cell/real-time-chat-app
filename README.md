# 💬 Real-Time Chat App

A full-stack real-time chat application built from scratch.

## Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Real-time:** Socket.io
- **Database:** MongoDB Atlas
- **Auth:** JWT + bcrypt
- **DevOps:** Docker + GitHub Actions

## Features
- ✅ Real-time messaging
- ✅ Multi-room chat
- ✅ Message persistence
- ✅ User avatars
- ✅ Typing indicators
- 🔜 JWT Authentication
- 🔜 Docker deployment
